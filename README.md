## 📥 Como Baixar os Arquivos

Como estes arquivos ultrapassam o limite padrão do Git (sendo superiores a 100MB), eles são hospedados de forma otimizada na seção de **Releases**. Siga os passos abaixo para baixar:

1. Acesse a página de **[Releases do Repositório](../../releases)**.
2. Na aba da versão desejada (geralmente a *Latest* / mais recente), role até a seção **Assets** (Ativos).
3. Clique sobre o arquivo desejado (`.mp4`, `.zip`, etc.) para iniciar o download automático.

## 📤 Como Adicionar Novos Vídeos/Arquivos (Para Contribuidores)

Se você faz parte da equipe e deseja adicionar novos vídeos ou arquivos grandes a este repositório, siga o processo padrão via **GitHub Releases**:

### Passo a passo para criar uma nova Release ou atualizar os arquivos:

1. **Prepare o arquivo:** Certifique-se de que o vídeo está compactado/exportado corretamente (ex: formato `.mp4` com codec H.264/H.265 para melhor compatibilidade).
2. **Vá para Releases:** Na página principal do repositório no GitHub, clique no link **Releases** na barra lateral direita (ou acesse `https://github.com/SEU-USUARIO/SEU-REPO/releases`).
3. **Nova Release:** Clique no botão **Draft a new release** (Rascunhar uma nova release).
4. **Defina a Tag:** 
   * Escolha ou crie uma nova tag de versão baseada na data (ex: `2026-10-01`).
   * Dê um título claro para a release (ex: `Atualização de Vídeos - Outubro/2026`).
5. **Anexe os arquivos:** 
   * Na caixa de texto de binários (**Attach binaries by dropping them here or selecting them**), arraste e solte seus arquivos de vídeo (cada um pode ter até 2 GB).
6. **Descreva as novidades:** No corpo da release, escreva um breve resumo do que foi adicionado.
7. **Publique:** Clique em **Publish release**.
8. **Atualize este README:** Volte ao repositório, edite este `README.md` incluindo o novo vídeo na tabela de índice acima para que fique fácil de encontrar!
